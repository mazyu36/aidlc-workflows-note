Design Agent

エージェント深掘り · ユーザーガイド › エージェント › 深掘り · 技術リファレンス: design-agent

aidlc-design-agent はあなたの UX/UI デザイナーである。Ideation でワイヤーフレームとコンセプトスケッチを作り、Inception でそれをインタラクション仕様付きの高忠実度モックアップへ育てる。情報アーキテクチャ、ナビゲーション設計、レスポンシブ挙動、アクセシビリティ要件を定義する。UI の無いプロジェクトでは、システムコンテキスト図と API 体験の設計を生む。

aidlc-design-agent は 2 つの stage をリードし、2 つを支援する。すべてのユーザー向けインターフェースが使いやすく、アクセシブルで、デザインシステムの標準と一貫することを保証する。

リードする stage

Stage Phase 説明
1.6 Rough Mockups Ideation 低忠実度ワイヤーフレームとコンセプトの可視化
2.5 Refined Mockups Inception インタラクション仕様とアクセシビリティを伴う高忠実度モックアップ

支援する stage

Stage Phase 貢献
2.4 User Stories Inception ストーリーをインタラクションの詳細と UX 受け入れ基準で豊かにする
2.6 Application Design Inception UI コンポーネント仕様の提供

期待できること

aidlc-design-agent がアクティブなとき、画面レイアウト・ユーザーフロー・インタラクションパターンの詳細な記述を markdown で生む。対象デバイス、アクセシビリティ要件、デザインシステムの選好を尋ねる。インタラクションを具体的な画面状態と遷移 — ローディング・成功・エラー・空・部分表示 — の言葉で記述する。

協働のしかた

aidlc-design-agent は aidlc-product-agent から intent とユーザーストーリーを、aidlc-architect-agent からコンポーネントの制約を受け取る。そのモックアップとインタラクション仕様は、実装のために aidlc-developer-agent へ、UX の受け入れテストのために aidlc-quality-agent へ引き継がれる。

主要原則

  • スキャンしやすさのための設計 — 重要なアクションは即座に見えなければならない
  • 一貫性は認知負荷を減らす — すべてのインタラクションパターンは予測可能であるべき
  • エラーメッセージよりエラー防止 — エラーを犯しにくくする
  • WCAG のアクセシビリティ準拠はベースラインであり、努力目標ではない
  • 最悪ケースのための設計 — 空の状態・エラー状態・遅い回線
