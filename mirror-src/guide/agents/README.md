# エージェント深掘り

ドメインエージェントごとに 1 ページ: そのドメイン、リード / 支援する stage、読み込む知識、協働のしかた。14 エージェントの全一覧は、11 のドメインエージェント、レビュー専任の 2 エージェント、適応ワークフローの composer から成る。この索引は stage の作業を実行する 11 のドメインエージェントを扱う。

レビュー専任のエージェントは独立したプロダクト・アーキテクチャの検査を行い、composer は適応的な stage 計画を提案・再形成する。3 つの役割グループすべてと、30 の狭い専門家ではなく 11 の広いドメインエージェントにした哲学は [エージェントの章](../06-agents.md) を参照。frontmatter の契約・ツール許可リスト・完全な比較マトリクスは、開発者リファレンスの [エージェントリファレンス](../../reference/agents/README.md) を参照。
